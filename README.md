# stm32-c-assembly-labs-Keil-Vision-5-
This repository contains practical lab work completed as part of the Microprocessors and UML course during my Master’s degree in Electronics, Signal Processing and Image Processing (EEA/TSI).  The objective was to explore embedded software development for ARM Cortex-M processors using Keil MDK-ARM (µVision 5).

*Objectives
- Create and configure embedded projects in Keil µVision 5.
- Understand the structure of ARM Cortex-M projects.
- Develop and compile programs in C and Assembly.
- Integrate Assembly routines into C programs.
- Explore debugging tools, registers and program execution.

* Lab Contents
- Project Setup: Creating and configuring a project in Keil µVision.
- Assembly Programming: Writing and compiling ARM Assembly code.
- C Programming: Developing and debugging C programs.
- C & Assembly Integration: Calling Assembly functions from C code.
- Debugging: Observing program execution and processor registers.

* Tools & Technologies: Keil MDK-ARM / µVision 5, ARM Cortex-M3, C, ARM Assembly.
